# 사용자 PC 검증 체크리스트 (부록 B 요약)

이 클라우드 세션은 GPU가 없고 huggingface.co 가 차단되어 있어 아래 항목은
사용자 PC(Windows 10/11 + NVIDIA 8 GB)에서 확인해야 합니다. 결과는 이슈로
남기거나 다음 세션에 전달해 주세요.

## P0 (이번 단계)

- [ ] `npm run tauri dev` 로 창이 뜨고 온보딩 → 홈이 동작하는가 (WebView2 Runtime 필요)
- [ ] 테마 4종(라이트/다크/시스템/고대비) 전환 시 **창 제목표시줄**도 같이 바뀌는가
- [ ] Windows 설정 > 접근성 > 대비 테마를 켜면 앱이 고대비 팔레트를 따르는가 (`forced-colors`)
- [ ] 한국어/영어 전환이 즉시 반영되고 재시작 후 유지되는가
- [ ] `%LOCALAPPDATA%\DocuLens\settings.json` 이 생성되고, `active_workspace` 를 직접 수정하면 다음 시작 시 반영되는가
- [ ] 워크스페이스 폴더에 `.doculens\{workspace.json, lock, models\, cache\, …}`, `inbox\`, `documents\`, `exports\` 가 생성되는가
- [ ] 같은 워크스페이스를 두 번째 인스턴스로 열면 잠금 안내가 뜨는가 (강제 열기 포함)
- [ ] 모델 관리자 > 하드웨어 감지에 GPU 이름 / VRAM / 드라이버 CUDA 버전 / CC 가 표시되는가 (NVML)
- [ ] 산정 티어가 가용 VRAM 기준 표와 일치하는가 (8 GB 카드 → `8 GB`, 권장 Q6_K/Q5_K_M/Q4_K_M)
- [ ] "필요 파일 목록" 텍스트의 Hugging Face URL 이 실제로 존재하는가 → 존재하면 크기·SHA-256 을 `models/registry.json` 에 고정하고 `verified: true` 로 변경
- [ ] 한글 IME 로 명령 입력 중 Enter 가 조합 도중에 전송되지 않는가 (어시스턴트, 명령 바, 팔레트)
- [ ] UI 배율 90~150% 가 Windows DPI(125%, 150%)와 독립적으로 동작하는가

- [ ] 검토 큐에서 Tab으로 "거부" 버튼에 간 뒤 Enter → 거부(승인 아님); 뷰어 이력 탭의 "이 값으로 복원"으로 수정 전 값이 돌아오는가
- [ ] 이미 검토 완료된 문서를 "표준 처리"하면 대체 확인 다이얼로그가 뜨는가; 병합 이름에 `..`·`/` 입력 시 거부되는가
- [ ] 실모델 KIE에서 엔진 로그에 "does not match the expected … format"(출력 파서 500)이 나오지 않는가; 나오면 seed·온도
      재시도로 복구되는가(작업 로그 "kie attempt N"); 문법 제약 생성 속도(t/s)가 문법 없는 OCR 생성과 큰 차이가 없는가

- [ ] 상단 "해석"이 기본 "모델"이고, "지난달 영수증 합계 알려줘"처럼 명령 단어가 섞인 질문이 집계 카드가 아니라 모델의 해석(질문이면 답변,
      명령이면 플랜)으로 나오는가; 플랜 카드 출처가 "모델"로 표시되는가
- [ ] 모델이 로드되지 않은 상태에서 문장을 보내면 키워드 추측 없이 "플래너 모델이 로드되지 않아…" 명확화 카드와 모델 로드 버튼이 뜨는가;
      모델 로드 중 첫 명령의 대기 시간(GPU 10~30초)이 "해석 중…"으로 표시되는가
- [ ] GPU에서 명령당 1~3초, 두 번째 명령부터 더 짧은가(프롬프트 캐시); CPU 전용 PC에서 "규칙(구형)"으로 바꾸면 종전처럼 즉시 해석되는가
- [ ] 명확화 카드의 답변란에 답을 적고 되묻기를 누르면 답이 사용자 말풍선으로 남고 카드가 "답변함"이 되며 새 해석 카드가 이어지는가;
      취소 버튼·Esc·"취소" 입력이 모델을 기다리지 않고 바로 카드를 닫는가("대기 중인 질문·플랜을 취소했습니다")
- [ ] 플랜 카드의 되묻기 입력란("검토 안 된 것도 같이")으로 플랜을 고쳐 다시 받을 수 있는가; `/테마 다크` 같은 슬래시 명령은 여전히 즉시 실행되는가
- [ ] 평가: `doculens-eval planner --engine <llama-server> --models-dir … --model qwen3.5-4b-q4km`로 골든셋 100건의 모델 경로
      정확도를 측정해 HANDOFF에 기록(규칙 경로 99%와 비교)
