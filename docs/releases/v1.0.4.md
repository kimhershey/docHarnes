# DocuLens 1.0.4

v1.0.3 이후의 정리 판입니다. 새 기능은 없습니다. 쓰이지 않던 코드와 옛 판의 데이터를 읽으려고 남겨 두었던 것들을 지웠고, 사용자에게 영어 오류 코드가 그대로 보이던 곳을 고쳤습니다.
설치·실행 방법은 [docs/RUN-GUIDE.md](https://github.com/kimhershey/docHarnes/blob/v1.0.4/docs/RUN-GUIDE.md), 사용자 PC에서 확인할 항목은
[docs/user-pc-checklist.md](https://github.com/kimhershey/docHarnes/blob/v1.0.4/docs/user-pc-checklist.md)의 "1.0.4" 절을 보세요.

## 고친 것

- 오류 코드 17개에 문구가 없어 화면에 영어 코드가 그대로 나오던 것을 고쳤습니다(예: 병합할 문서 수가 맞지 않을 때, 표가 없는 문서의 표 내보내기, 작업 공간 밖의 폴더를 고른 경우).

## 지운 것

- 어디에서도 부르지 않던 코드: 화면이 쓰지 않던 명령 9개, 쓰이지 않던 함수와 상수.
- 요약의 `target` 칸(문서별 · 묶음). 1.0.3에서 요약은 결과 하나가 됐고, 이제 칸 자체가 없습니다.
- 설정 전용 동작 5개(`set_theme` · `set_language` · `set_profile` · `set_model` · `set_inbox_watch`). 설정 변경은 `set_setting` 하나로 합니다. "다크 테마로 바꿔줘" 같은 문장의 동작은 같습니다.
- 설정의 옛 짧은 이름(`render_dpi` 등 0.6.0 이전의 별칭).
- 숨겨 두었던 옛 기본 양식 6종(세금계산서 · 계산서 · 영수증 · 사업자등록증 · 계약서 · 신청서)과 옛 문서 템플릿 4종(견적서(품목) · 거래명세서 · 계약서 · 회의록의 옛 틀). 기본 양식은 소프트웨어 개발 문서 13종입니다.
  세금계산서나 영수증 양식이 필요하면 "양식 등록"으로 직접 등록해 쓰세요.
- 지난 판의 계획서 · 점검 목록 · 릴리스 노트(1.0.2 이하)와 인수인계 문서의 지난 절. git 기록에는 남아 있습니다.

## 동작이 달라지는 점

- **1.0.2 이하에서 만든 대화 카드 중 일부는 다시 실행할 수 없습니다**: 요약 계획에 `target`이 들어 있거나 설정 전용 동작이 들어 있는 카드입니다. 대화의 글과 결과는 그대로 보입니다. 같은 문장을 다시 치면 됩니다.
- **옛 문서 템플릿 4종으로 만든 저장 초안은 초안 목록에 나오지 않습니다**(파일은 작업 공간의 `.doculens/drafts/`에 남아 있습니다). 견적서 · 개발 계약서 · 회의록 템플릿으로 새로 만드세요.
- 이미 쓰던 작업 공간의 옛 기본 양식 6종은 지워지지 않습니다. 양식 목록에 저장된 양식으로 그대로 남고(기본은 꺼짐), 그 양식으로 처리한 문서의 값도 그대로입니다. 새로 만드는 작업 공간에는 생기지 않습니다.
- 양식을 말하지 않은 초안의 기본 틀(보고서)과 "공문 형식으로"는 종전과 같습니다.

## 확인한 것

- Rust 테스트 · clippy · 형식 검사, 웹 타입 검사 · 단위 테스트 · 브라우저(모의 백엔드) E2E, 플래너 골든셋 회귀 게이트(201문장, 95.5 %로 1.0.3과 같음).

## 확인하지 못한 것

- 실제 Windows 설치본에서의 동작(사용자 PC 체크리스트 "1.0.4" 절).
- 실제 모델로 다시 재지 않았습니다. 모델에게 보여 주는 동작 목록 · 문법은 1.0.3과 같습니다(설정 전용 동작 5개는 1.0.0부터 모델에게 보이지 않았습니다).
