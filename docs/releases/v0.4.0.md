# DocuLens 0.4.0

v0.3.0(2026-11-10) 이후의 변경 사항입니다. 설치·실행 방법은 [docs/RUN-GUIDE.md](https://github.com/kimhershey/docHarnes/blob/v0.4.0/docs/RUN-GUIDE.md), 사용자 PC에서 확인할 항목은
[docs/user-pc-checklist.md](https://github.com/kimhershey/docHarnes/blob/v0.4.0/docs/user-pc-checklist.md)의 "0.4.0" 절을 보세요. 이 판은 **Lite 설치파일만** 배포합니다.

## 설치파일

| 파일 | 내용 |
|---|---|
| `DocuLens-Setup-Lite-0.4.0-x64.exe` | 앱 + llama-server CPU·Vulkan 엔진 팩(b12066) + PDFium + ko-dic (약 50 MB) |
| `*.sha256` | 설치파일의 SHA-256 — `certutil -hashfile DocuLens-Setup-Lite-0.4.0-x64.exe SHA256`으로 비교 |
| `THIRD-PARTY-NOTICES.md`, `sbom.cdx.json` | 제3자 고지와 CycloneDX SBOM |

- 모델(GGUF)은 설치파일에 들어 있지 않습니다. 첫 실행 뒤 모델 관리자에서 내려받거나(Hugging Face), USB로 복사해 드롭인합니다 — 방식은 0.3.0과 같고
  **목록만 바뀌었습니다**.
- 엔진 태그는 b12066 그대로입니다. NVIDIA GPU는 Release v0.1.0의 CUDA 엔진 팩(`DocuLens-EnginePack-cu121-b12066.zip` / `-cu129-`)을 `%LOCALAPPDATA%\DocuLens\engines\b12066\cu121\`(`cu129\`)에 풀어 이 Lite와 함께 씁니다. Full 설치파일(v0.2.0)은 0.2.0 앱을 설치하므로 이 판을 대신할 수 없습니다 — 0.2.0 앱은 이후 판이 연 작업 공간을 열지 못하고, 그 위에 이 Lite를 설치 화면의 기본 선택(이전 판을 제거한 뒤 설치)으로 올리면 Full에 들어 있던 CUDA 팩도 함께 지워집니다.
- 사용자 단위 설치(관리자 권한 불필요), Windows 10 1803+/11 x64. 0.3.0 작업 공간은 그대로 열립니다(DB 마이그레이션 없음).

## 모델 교체 — 중국계 모델 제외, Gemma 4 + EmbeddingGemma 2

사용자 결정(2026-11-10)에 따라 **중국계 개발사의 모델을 모두 제외**하고, 라이선스가 Apache-2.0이며 파일 1개가 8 GB를 넘지 않는 모델로 바꿨습니다.

| 역할 | 0.3.0 | 0.4.0 |
|---|---|---|
| 비전 언어 모델 | Qwen3.5 2B/4B/9B/27B, Qwen3-VL 4B (Alibaba) | **Gemma 4 E2B / E4B / 12B** (Google DeepMind, Apache-2.0) |
| 임베딩 | bge-m3 (BAAI, 1024차원) | **EmbeddingGemma 2** (Google, Apache-2.0, 768차원, Q8_0 310 MB) |

- **레지스트리 7종**: `gemma4-e2b-q4km`(CPU·저여유) · `gemma4-e2b-q8`(CPU 정확도·6 GB) · `gemma4-e4b-q4km` / `q5km` / `q6k`(8 GB 적응형) ·
  `gemma4-12b-q4km`(12 GB+) · `embed-gemma2-q8`. 티어 자동 선택은 GPU 없음 → E2B Q4_K_M, 6 GB → E2B Q8_0, 8 GB → E4B(여유 VRAM 7.1 GiB 이상 Q6_K,
  6.0 GiB 이상 Q5_K_M, 그 외 Q4_K_M), 12 GB 이상 → 12B Q4_K_M.
- **엔진은 그대로**(llama.cpp b12066이 `gemma4`·`gemma-embedding2`와 Gemma 4 비전 프로젝터를 지원). 생각(thinking) 채널은 꺼서 씁니다.
- **이미지 해상도**: Gemma 4의 비전 토큰은 48 px 단위, 최대 1,120 토큰입니다. 페이지 렌더는 이 상한에 맞춰 최대 2.58 MP까지 쓰므로 0.3.0의 OCR 기본
  해상도(1.5 MP)보다 높습니다. 잔글씨 프로파일은 상한 1,120으로 고정됩니다.
- **지식 베이스 임베딩**: 차원이 1024 → 768로 바뀌므로 EmbeddingGemma 2를 설치하고 "임베딩 실행"을 하면 기존 벡터를 비우고 다시 채웁니다(색인·FTS 검색은
  그대로). 질의·문서 접두어(`task: search result | query:` / `title: none | text:`)는 자동으로 붙습니다.
- **기존 Qwen 모델 폴더**: 지우지 않습니다. "사용자 추가 모델"로 계속 인식·로드되지만 추천·다운로드 목록에는 나오지 않습니다. 설정에 남은 옛 모델 id는
  기본값으로 돌아갑니다.
- 라이선스 정책(`docs/LICENSE-POLICY.md`)에 "중국계 모델 제외" 원칙과 Gemma 4 / EmbeddingGemma 2(Apache-2.0) 허용을 명시했습니다. Gemma 3 이하와
  1세대 EmbeddingGemma(Gemma Terms)는 계속 금지입니다.

## 알려진 제약

- 한국어 문서 OCR·추출 품질은 이 저장소의 CI에서 측정하지 못합니다(가중치 없음). 사용자 PC에서 `doculens-eval pipeline --model gemma4-e4b-q5km`로
  0.3.0 결과와 비교해 주세요. 티어별 VRAM 요구치(`min_free_vram_mib`)는 추정값이라 실측 후 조정이 필요할 수 있습니다.
- 모델 파일의 크기·SHA-256은 미고정(`verified: false`)입니다. 처음 받은 뒤 "해시 검증" 값을 `models/registry.json`에 고정해 주세요.
- 다운로드 저장소(unsloth / ggml-org)의 파일 이름이 바뀌면 레지스트리를 수정해야 합니다.
- UI 배율 150 %에 1280 px 폭 이하 창의 제약은 0.2.0과 같습니다.
