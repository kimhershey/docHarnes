## 무엇이 달라졌나

사용자 PC에서 보고된 문제입니다. "AAA 프로젝트 내에서 AAA 가 무엇인지 요약해서 설명해줘"에 어시스턴트가 문서 유형을 되물었고, "유형 상관없이 전부"라고 답하자
"명령을 해석하지 못했습니다(unknown document type 'all' …)"가 나왔습니다. 질문에는 문서 유형이 필요 없습니다.

원인은 세 가지였습니다. 모델이 쓰는 대상 범위에 프로젝트를 적을 자리가 없어 가장 가까운 유형 칸을 골랐고, 유형 칸은 아무 글자나 쓸 수 있는데 검증은 목록에 없는 값을 실행 불가로 처리했으며,
모델의 되묻기는 필요한지 따지지 않고 그대로 보여 줬습니다.

1. **유형은 사용자가 말했을 때만 조건입니다.**
   - 유형 칸의 `all`·"전체"·"모든 문서" 같은 값은 오류가 아니라 "유형 조건 없음"입니다.
   - 질문·검색·설명·요약에서 목록에 없는 유형이 나오면 그 조건만 빼고 진행하고, 카드에 "'…' 유형은 없어 유형 조건 없이 진행합니다"라고 알립니다.
   - 질문·검색·설명에서 문장에 없는 유형 조건이 붙으면 빼고 찾습니다("문장에 없는 유형 조건('…')은 빼고 찾습니다"). 문장이 유형을 말하면("계약서에서 …") 그대로 둡니다.
2. **질문에는 되묻지 않고 답합니다.** 질문·검색·요약으로 읽힌 문장에 모델이 유형을 되묻거나, 문장에 프로젝트 이름이 있거나 프로젝트가 열려 있는데 되물으면, 되묻기 대신 그 범위의 문서에서 찾아 답합니다.
   앱이 스스로 정할 수 없는 물음("어떤 문서를 요약할까요?")은 그대로 묻습니다.
3. **문서를 바꾸는 명령은 유형을 계속 확인합니다.** 삭제·이동·유형 지정 같은 명령에서 유형을 알아보지 못하면 종전처럼 멈추되, 영어 검증 메시지 대신 "'…' 문서 유형을 알아보지 못했습니다. 유형을 빼고 다시 말씀해 주시거나
   다음 중에서 골라 주세요: …"라고 안내합니다.
4. **규칙 우선 해석 모드**에서 되묻기에 답한 문장을 읽을 때 어시스턴트가 한 질문의 낱말을 명령으로 읽지 않습니다. 위 되묻기에 "유형 상관없이 전부"라고 답하면 질문에 예로 든 유형 이름 때문에
   "문서 유형을 테스트 결과서로 설정"으로 읽히던 문제입니다(기본 모드인 모델 우선에는 해당 없음).
5. 모델 지시문에 "유형은 사용자가 유형을 말했을 때만 쓰고 되묻지 않는다, 프로젝트 이름은 유형이 아니다"를 넣었습니다.

## 말에 따라 달라지는 동작

| 말 | 하는 일 | 결과 |
|---|---|---|
| "… 검색해줘 / 찾아줘" | 범위의 문서에서 맞는 대목을 찾습니다. 글을 새로 쓰지 않습니다. | 문서·쪽·대목 목록 |
| "… 알려줘 / …가 뭐야?" | 맞는 대목을 찾은 뒤 모델이 그 근거로 답을 씁니다. | 답변 글 + 출처 |
| "… 설명해줘" | 문장·용어·조항을 가리키면("이 조항 설명해줘", "…의 뜻") 그 대목을 풀어 설명하고, 그 밖에는 "알려줘"와 같습니다. | 설명 글 + 출처 |
| "… 요약해줘" | 범위의 문서 내용을 요약합니다(문서별 또는 묶음 하나). 문서가 많으면 오래 걸립니다. | 요약 글 |
