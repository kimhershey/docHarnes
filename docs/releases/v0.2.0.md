# DocuLens 0.2.0

v0.1.0(2026-11-08) 이후의 변경 사항입니다. 설치·실행 방법은 [docs/RUN-GUIDE.md](https://github.com/kimhershey/docHarnes/blob/v0.2.0/docs/RUN-GUIDE.md), 사용자 PC에서 확인할 항목은
[docs/user-pc-checklist.md](https://github.com/kimhershey/docHarnes/blob/v0.2.0/docs/user-pc-checklist.md)를 보세요.

## 설치파일

| 파일 | 내용 |
|---|---|
| `DocuLens-Setup-Lite-0.2.0-x64.exe` | 앱 + llama-server CPU·Vulkan 엔진 팩 + PDFium + ko-dic (약 50 MB) |
| `DocuLens-Setup-Full-0.2.0-x64.exe` | Lite + CUDA 엔진 팩 cu121(드라이버 CUDA 12.1~12.7)·cu129(12.8+, RTX 50 포함) (약 1.1 GB, 설치 공간 3.5 GB 이상) |
| `*.sha256` | 각 설치파일의 SHA-256 — `certutil -hashfile DocuLens-Setup-Lite-0.2.0-x64.exe SHA256`으로 비교 |
| `THIRD-PARTY-NOTICES.md`, `sbom.cdx.json` | 제3자 고지와 CycloneDX SBOM |

- 모델(GGUF)은 어느 설치파일에도 들어 있지 않습니다. 첫 실행 뒤 모델 관리자에서 준비합니다.
- CUDA 엔진 팩 zip(`DocuLens-EnginePack-cu121-b12066.zip`, `-cu129-`)은 엔진 태그가 같아(b12066) v0.1.0 자산을 그대로 씁니다.
  Lite에 CUDA 팩만 나중에 추가하려면 그 zip을 `%LOCALAPPDATA%\DocuLens\engines\b12066\` 아래에 풉니다.
- 사용자 단위 설치(관리자 권한 불필요), Windows 10 1803+/11 x64.

## 새 기능

- **끌어다 놓기** — 라이브러리 문서를 어시스턴트·홈·지식 베이스 컬렉션·프로젝트·문서 생성 원본·양식 등록·병합으로 끌어다 놓고,
  OS 파일을 문서를 추가하는 모든 화면에 놓을 수 있습니다(사이드바에 올려 두면 해당 화면이 열립니다).
- **입력 형식 확장** — XLSX·PPTX·텍스트(txt/md/csv/html…)와 구형 XLS/XLSB/ODS·DOC·PPT·RTF·HML을 읽습니다. 파일 형식은
  확장자가 아니라 내용(매직 바이트·zip/CFB 항목)으로 판별하므로 확장자가 틀려도 처리됩니다. PPTX는 슬라이드 고유 크기와
  배치된 도형을 유지해 변환합니다.
- **뷰어 글자 레이어** — 페이지 이미지 위의 글자를 드래그해 선택하고 그 자리에서 고칩니다. 선택 → 필드 값 지정, 선택 문장
  설명(Ctrl+E). 고친 글자는 흰 바탕 파란 글씨로 표시되고 다시 렌더·회전 저장·재시작 뒤에도 유지됩니다. 오른쪽 패널은
  AI 검색과 이력만 남겼습니다.
- **어시스턴트 기억** — 이전 대화와 현재 화면(문서·페이지·선택·폴더·프로젝트)을 맥락으로 넘기고 후속 질문을 인식합니다.
- **어시스턴트 해석 방식** — `/` 명령을 제외한 모든 입력을 모델이 해석합니다(규칙 우선 → 모델 우선). 명확화 카드에
  **되묻기·취소** 버튼이 있고 이 둘과 단독 "취소"는 추론 없이 규칙으로 바로 처리합니다. 프롬프트 캐시로 두 번째 호출부터
  빨라집니다. "해석: 규칙(구형)"은 CPU 전용 PC용 선택지로 남겨 두었습니다.
- **프로젝트 자동 분류** — 라이브러리·지식 베이스 문서를 제목·내용으로 프로젝트별로 제안하고(규칙 점수 + 선택적 모델 판단)
  미리보기 뒤 적용합니다. 프로젝트에 키워드를 둘 수 있습니다.
- **양식 화면** — 화면 전체가 문서·파일 드롭을 받고, 필드 발견이 모델 없이도 텍스트 규칙으로 동작합니다.

## 수정

- 표 안의 글자: 디지털 PDF의 글자 박스를 셀 단위 시각적 행으로 묶고, 스캔 표(OCR)는 괘선을 지운 뒤 셀마다 배치해 행이 섞이지
  않습니다. 이전 버전에서 저장된 글자 레이어도 열 때 다시 묶입니다.
- UI 배율 125~150 %에서 라이브러리 카드·목록·뷰어 썸네일·검토 큐의 글자가 잘리던 문제(px 고정 상자 → rem·측정 기반).
  상단바 Ctrl+K 표시와 상태바도 잘리지 않습니다.
- PPTX 이미지 깨짐·가로세로 비율, 양식 등록 드롭 오동작, Markdown으로 저장한 초안의 라이브러리 등록.
- Full 설치파일이 NSIS의 2 GiB 솔리드 블록 한계를 넘던 문제(파일별 LZMA 압축).
- PDF 글자 박스를 페이지 박스 기준으로 정규화하고 내장 회전을 반영합니다.

## 알려진 제약

- UI 배율 150 %에 1280 px 폭 이하 창이면 라이브러리 필터가 여러 줄로 줄바꿈되고 목록에 가로 스크롤이 생깁니다. 최소 창
  (960×600)에 150 %는 상단바가 가로로 넘칩니다. 1600 px 이상 폭을 권장합니다.
- 실제 Qwen3.5-4B 모델 경로의 플래너 정확도는 이 저장소의 CI에서 측정하지 못합니다(가중치 없음). 사용자 PC에서
  `doculens-eval planner --engine …`로 측정합니다.
- 모델 경로는 GPU에서 명령당 1~3초, CPU 전용에서는 10초 안팎입니다. CPU 전용 PC는 "해석: 규칙(구형)"이 빠릅니다.
