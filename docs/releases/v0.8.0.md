# DocuLens 0.8.0

v0.6.0 이후의 변경 사항입니다(0.7.0은 Release로 게시되지 않았고, 그 변경은 이 판에 들어 있습니다 — [0.7.0 변경 내용](https://github.com/kimhershey/docHarnes/blob/v0.8.0/docs/releases/v0.7.0.md)).
설치·실행 방법은 [docs/RUN-GUIDE.md](https://github.com/kimhershey/docHarnes/blob/v0.8.0/docs/RUN-GUIDE.md), 사용자 PC에서 확인할 항목은
[docs/user-pc-checklist.md](https://github.com/kimhershey/docHarnes/blob/v0.8.0/docs/user-pc-checklist.md)의 "0.8.0" 절을 보세요. 이 판도 **Lite 설치파일만** 배포합니다.

이 판은 두 가지를 합니다. ① AI 어시스턴트가 문장을 읽는 방식을 다시 짰습니다(2026-11-11 사용자 PC 보고: 설정 명령이 엉뚱한 설정을 바꿈, 인사에 빈 플랜 카드, "프로젝트 별 요약"이 전체 요약으로 바뀜).
② 0.7.0 전체 점검에서 나온 수정 필요 목록([docs/audit/v0.7.0.md](https://github.com/kimhershey/docHarnes/blob/v0.8.0/docs/audit/v0.7.0.md))을 처리했습니다.

## 설치파일

| 파일 | 내용 |
|---|---|
| `DocuLens-Setup-Lite-0.8.0-x64.exe` | 앱 + llama-server CPU·Vulkan 엔진 팩(b12066) + PDFium + ko-dic |
| `*.sha256` | 설치파일의 SHA-256 — `certutil -hashfile DocuLens-Setup-Lite-0.8.0-x64.exe SHA256`으로 비교 |
| `THIRD-PARTY-NOTICES.md`, `sbom.cdx.json` | 제3자 고지와 CycloneDX SBOM |

- 모델(GGUF)은 설치파일에 들어 있지 않습니다. 설정 > AI 모델에서 내려받거나 USB로 복사해 드롭인합니다(0.4.0과 같은 목록 — Gemma 4 + EmbeddingGemma 2).
- 엔진 태그는 b12066 그대로입니다. NVIDIA GPU는 Release v0.1.0의 CUDA 엔진 팩(`DocuLens-EnginePack-cu121-b12066.zip` / `-cu129-`)을 `%LOCALAPPDATA%\DocuLens\engines\b12066\cu121\`(`cu129\`)에 풀어 이 Lite와 함께 씁니다.
- 0.6.0·0.7.0 작업 공간은 그대로 열립니다.
