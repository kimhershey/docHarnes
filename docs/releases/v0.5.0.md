# DocuLens 0.5.0

v0.4.0(2026-11-10) 이후의 변경 사항입니다. 설치·실행 방법은 [docs/RUN-GUIDE.md](https://github.com/kimhershey/docHarnes/blob/v0.5.0/docs/RUN-GUIDE.md), 사용자 PC에서 확인할 항목은
[docs/user-pc-checklist.md](https://github.com/kimhershey/docHarnes/blob/v0.5.0/docs/user-pc-checklist.md)의 "0.5.0" 절을 보세요. 이 판은 **Lite 설치파일만** 배포합니다.

## 설치파일

| 파일 | 내용 |
|---|---|
| `DocuLens-Setup-Lite-0.5.0-x64.exe` | 앱 + llama-server CPU·Vulkan 엔진 팩(b12066) + PDFium + ko-dic (약 50 MB) |
| `*.sha256` | 설치파일의 SHA-256 — `certutil -hashfile DocuLens-Setup-Lite-0.5.0-x64.exe SHA256`으로 비교 |
| `THIRD-PARTY-NOTICES.md`, `sbom.cdx.json` | 제3자 고지와 CycloneDX SBOM |

- 모델(GGUF)은 설치파일에 들어 있지 않습니다. 첫 실행 뒤 설정 > AI 모델에서 내려받거나(Hugging Face) USB로 복사해 드롭인합니다(0.4.0과 같은 목록 — Gemma 4 + EmbeddingGemma 2).
- 엔진 태그는 b12066 그대로이므로 CUDA 엔진 팩(v0.1.0)과 Full 설치파일(v0.2.0)을 그대로 쓸 수 있습니다.
- 사용자 단위 설치(관리자 권한 불필요), Windows 10 1803+/11 x64. 0.4.0 작업 공간은 그대로 열립니다(DB 마이그레이션 0010 — 열 추가만, 데이터 이동 없음).

## 프로젝트 중심 통합 (A안)

지식 베이스의 "컬렉션"과 프로젝트가 비슷한 역할로 혼란스럽다는 검토 결과에 따라 **문서 묶음은 프로젝트 하나**로 합쳤습니다(사용자 결정 2026-11-10).

| | 0.4.0 | 0.5.0 |
|---|---|---|
| 문서 묶음 | 지식 베이스의 컬렉션 + 프로젝트(별개) | **프로젝트 = 업무 문서 + 참고 자료**. 프로젝트 밖 규정·지침은 프로젝트 목록 맨 위의 **공통 참고 자료** |
| 어시스턴트 범위 | 전체·폴더·선택·현재 문서·첨부·지식 베이스·컬렉션 | **전체 · 현재 프로젝트 · 선택/첨부 문서** |
| 질문 입구 | 검색 화면, 어시스턴트, 지식 베이스의 질문 테스트 | **AI 어시스턴트 하나**("근거만 찾기" = 모델 호출 없이 검색 결과만) |

- **현재 프로젝트 범위** = 그 프로젝트의 업무 문서 ∪ 프로젝트 참고 자료 ∪ 활성 공통 참고 자료. 어시스턴트·근거만 찾기·문서 작성("참고 자료 사용")·플래너 `answer`가 같은 규칙을 쓰고,
  근거 칩이 업무 문서/참고 자료를 구분합니다. 선택·첨부 문서로 물어도 프로젝트의 참고 자료는 함께 봅니다.
- **프로젝트에 넣기** 대화상자 하나가 "프로젝트에 추가"·"지식 베이스에 추가"·"프로젝트로 분류"를 대신합니다(대상: 프로젝트 또는 공통 참고 자료, 종류: 업무 문서 또는 참고 자료,
  자동 분류 제안, 파일에서 가져오기). 참고 자료로 넣은 문서는 역할이 "참고 자료"가 됩니다.
- 프로젝트 상세 탭: **문서 · 참고 자료 · 규칙 · 결과(검사·관계·리포트) · 설정**. 프로젝트 이름을 바꾸면 참고 자료 묶음 이름이 따라오고, 프로젝트를 지우면 묶음만 사라집니다(문서는 남음).
- 어시스턴트 명령 "선택한 문서를 ○○ 프로젝트에 **참고 자료로** 넣어줘"(`add_to_project.as_reference`)를 이해합니다.
- 기존 컬렉션은 모두 공통 참고 자료의 묶음이 됩니다(데이터 이동 없음). 폴더 감시 설정은 없어졌습니다. 용어집·임베딩 모델·색인은 작업 공간 전역입니다.

## GUI 정리

- 어시스턴트의 "해석: 모델/규칙(구형)" 선택은 설정 > 일반 > 고급으로. 상태바는 AI 엔진 상태(모델 이름) + 작업 배지만.
- 문서함의 집계 바는 없애고(같은 질문은 AI 어시스턴트가 답함) 다시 렌더·재스캔·inbox 감시는 우클릭 메뉴와 설정 > 처리로.
- 사이드바 드롭 대상은 문서함(가져오기)·프로젝트·문서 작성만.
