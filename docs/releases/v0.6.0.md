## 설치파일

| 파일 | 내용 |
|---|---|
| `DocuLens-Setup-Lite-0.6.0-x64.exe` | 앱 + llama-server CPU·Vulkan 엔진 팩(b12066) + PDFium + ko-dic (약 50 MB) |
| `*.sha256` | 설치파일의 SHA-256 — `certutil -hashfile DocuLens-Setup-Lite-0.6.0-x64.exe SHA256`으로 비교 |
| `THIRD-PARTY-NOTICES.md`, `sbom.cdx.json` | 제3자 고지와 CycloneDX SBOM |

- 모델(GGUF)은 설치파일에 들어 있지 않습니다. 설정 > AI 모델에서 내려받거나 USB로 복사해 드롭인합니다(0.4.0과 같은 목록 — Gemma 4 + EmbeddingGemma 2).
- 엔진 태그는 b12066 그대로이므로 CUDA 엔진 팩(v0.1.0)과 Full 설치파일(v0.2.0)을 그대로 쓸 수 있습니다.
- 0.4.0·0.5.0 작업 공간은 그대로 열립니다(0.5.0의 마이그레이션 0010·0011 포함; 0.6.0은 DB 변경 없음). 0.5.0의 화면 구성(문서함 · AI 어시스턴트 · 검토함 · 프로젝트 · 문서 작성 · 작업 현황 · 설정, 프로젝트 = 업무 문서 + 참고 자료)도 이 판에 모두 들어 있습니다.

## AI 어시스턴트가 소프트웨어 기능 전부를 수행

화면에서 할 수 있는 일은 이제 모두 말로도 됩니다(사용자 결정 2026-11-10). 플랜 카드 → 확인 → 실행 → 되돌리기의 틀은 그대로이며, 삭제·네트워크(모델 다운로드)·엔진 정지·워크스페이스 닫기·파기 같은 동작은 확인 카드를 거칩니다.

| 묶음 | 새로 말로 되는 것 (예) |
|---|---|
| 문서 | 회전("이 문서 90도 돌려줘"), 다시 렌더("300 DPI로 다시 렌더"), 분할("3쪽부터 나눠줘" / "5쪽마다 분할"), 병합("선택한 문서 하나로 합쳐서 '계약 묶음'"), 제목("제목을 '2026 공급계약'으로"), 글자 바꾸기("'㈜한빛'을 '(주)한빛'으로 바꿔줘"), 역할("참고 자료로 표시"), 파일 경로로 가져오기 |
| 참고 자료 | 묶음 만들기·이름·삭제·사용/사용 안 함·문서 넣기/빼기("'사규' 참고 자료 묶음 만들어", "선택 문서를 사규 묶음에 넣어"), 용어집("용어 'MM'은 '맨먼스'로 등록"), 판 표시("2024년판으로 표시", "버전 표시 해제") |
| 프로젝트 | 이름·기간·담당·키워드 수정("한빛 납품 프로젝트 종료일 12월 31일"), 삭제, 문서 빼기, 자동 분류("미배정 문서 프로젝트로 자동 분류"), 템플릿 저장·삭제 |
| 양식·추출 항목 | 기본값("견적서 양식 기본으로"), 사용/사용 안 함, 삭제, 이름 변경 |
| 설정 | 설정 카탈로그 46개 항목 전부("UI 배율 125%로", "자동 임베딩 꺼줘", "검토 임계값 0.9", "절전 방지 켜") |
| 모델·엔진·워크스페이스·유지보수 | 모델 받기·가져오기·삭제·해시 검증·벤치마크·로드/언로드·티어·백엔드("12B 모델 받아줘"), 엔진 켜기/끄기, 워크스페이스 열기/만들기/닫기, 지금 파기 실행·끝난 작업 지우기·다시 검사 |

- 플래너 op는 43개에서 **62개**로 늘었고, 설정은 `set_setting`이 7개 키 대신 **카탈로그 경로**(`processing.render_dpi` 등 46개 + 옛 키 별칭)를 씁니다.
- **2단계 해석**: 모델은 먼저 명령의 계열(질문 · 문서 · 참고 자료 · 프로젝트 · 양식 · 문서 작성 · 집계/내보내기 · 시스템)을 고른 뒤 그 계열의 op 표로만 플랜을 만듭니다. 호출당 프롬프트가 종전(≈5.5K 토큰)보다 작아졌고(계열 선택 ≈0.6K, 플랜 ≈2~3K), 계열이 틀리면 전체 표로 한 번 더 시도합니다. 규칙(구형) 해석과 골든셋(125건, 99.2%)은 그대로입니다.
- 원본 파일은 바뀌지 않습니다(회전·글자 수정은 캐시·DB, 분할·병합은 새 파일). 파일 선택 창처럼 OS 창이 필요한 동작은 경로를 말하거나 파일을 끌어다 놓습니다.

## 알려진 제약

- 초안(문서 작성) 편집·저장은 편집기 작업이라 명령으로 두지 않았습니다(초안 생성은 됨). 휴지통 복원은 화면에도 없어 범위 밖입니다.
- 작은 모델(E2B)의 계열 선택 정확도는 사용자 PC에서 확인이 필요합니다(체크리스트).
