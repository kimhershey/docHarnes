## 1. 프로젝트의 문서와 참고 자료가 한 탭에

프로젝트 상세의 "문서"와 "참고 자료" 탭이 **"문서" 탭 하나**가 되었습니다(탭: 문서 · 규칙 · 결과 · 설정). 표에 **구분** 열(업무 문서 / 참고 자료)이 있고,
구분 버튼을 누르면 서로 바꿀 수 있습니다. 위의 필터(전체 / 업무 문서 / 참고 자료)로 거르고, "문서함에서 고르기"에서 넣을 구분을 고릅니다.
"파일에서 가져오기"는 참고 자료로 들어갑니다. 끌어다 놓기는 종전처럼 업무 문서로 들어갑니다. 저장 구조(업무 문서 = 프로젝트 문서, 참고 자료 = 프로젝트 참고 묶음)와
검색 범위·정합성 검사는 그대로입니다. 옛 "참고 자료 탭" 링크는 문서 탭으로 열립니다.

## 2. 문서 작성 — 본문 문단 추가·제거·이동

편집기의 본문 블록마다 도구 막대가 생겼습니다: 뒤에 문단 / 절 제목 / 목록 추가, 삭제, 위·아래 이동, 제목 수준(2·3) 전환. 본문이 비어 있으면 "문단 추가" 버튼이 있습니다.
검토 항목(`body[n]`)은 블록을 넣고 빼도 올바른 블록을 가리킵니다.

## 3. 문서 작성 — 스크롤 정리

가운데 미리보기는 A4 시트를 **창 폭에 맞춰 축소**해 보여 줍니다(가로 스크롤 없음; "100 %"로 실제 크기 전환). 미리보기·메모 영역이 화면 전체를 밀어내지 않도록 각 영역이
자체 스크롤만 가집니다.

## 4. 양식 등록이 다시 보입니다

설정 > 양식·추출 항목의 "양식 등록"(과 문서함의 병합 대화상자)이 화면 아래로 밀려나 보이지 않던 문제를 고쳤습니다(배경만 어두워지고 아무 일도 없어 보이던 증상).
양식 도출 작업이 다른 엔진 작업(가져오기 뒤 자동 분류 등) 뒤에서 기다릴 때는 그렇다고 안내합니다.

## 5. 문서 작성 — 초안 어시스턴트

"재생성 지시" 패널이 **초안 어시스턴트**가 되었습니다. 범위를 고르고(전체 / n절 다시 쓰기 / n절 뒤에 새 절 / 끝에 새 절) 지시를 적으면 모델이 그 부분만 고쳐 씁니다
(필드·표·다른 절은 그대로). 편집기의 절 제목 옆 "AI 수정"을 누르면 그 절이 범위로 잡힙니다. 전체 재생성은 분할 생성에서도 모든 절에 지시가 전달됩니다.
AI 어시스턴트 화면에서도 됩니다 — 문서 작성 화면에 초안을 연 채 "3절 다시 써줘, 숫자는 그대로", "결론 절 추가해줘", "초안 전체 격식체로"(새 op `revise_draft`).

## 6. AI 어시스턴트 — 채팅 세션

왼쪽에 **채팅 목록**이 생겼습니다. "새 채팅"으로 대화를 나누고, 이전 대화를 골라 이어서 쓰며, 이름 바꾸기·삭제가 됩니다. 대화는 워크스페이스 DB에 저장되어 앱을 다시
열어도 남고, 설정 > 보존 기간의 "대화 기록" 일수가 지나면 지워집니다. 첨부·기억(최근 8턴)은 세션별입니다.

## 7. 긴 파일 이름

긴 파일 이름을 가진 문서를 추가할 때 양식 도출 요약 배지, 양식 등록·가져오기·참고 자료 가져오기 목록의 배지가 UI 배율에 따라 상자 밖으로 나가던 문제를 고쳤습니다
(이름은 줄임표로, 전체 이름은 마우스를 올리면). 대화상자와 배지의 공통 스타일을 고쳐 같은 종류의 문제가 다른 화면에서도 생기지 않습니다.
